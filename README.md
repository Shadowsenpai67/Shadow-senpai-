# Anime World: Otaku Central

This repository is being repurposed from ShadowPlay into **Anime World: Otaku Central**, an anime discovery and editorial starter website.

## Current pages
- `/` — homepage and anime universe cards
- `/anime` — One Piece, Naruto, Bleach and broader anime hub
- `/news` — starter guide/article library (not a live news feed)
- `/merch` — merchandise categories prepared for verified affiliate links

## Stack
- Next.js App Router
- React
- TypeScript
- Responsive CSS

## Important before monetisation
- No affiliate programme is connected yet and no commissions are guaranteed.
- Confirm each programme's publisher eligibility, allowed traffic sources, payout threshold and payment method before adding links.
- Confirm that its payout method can be received in the owner's Raenest USD account; do not assume USD account details are supported.
- Keep affiliate disclosures visible and label sponsored/affiliate links clearly.
- Do not scrape/copy articles or use copyrighted anime artwork without permission. The visual identity uses CSS graphics and generic decorative imagery rather than official character art.
- The news page is a starter library, not a claim of live or verified breaking news.

## Deploy
The existing Vercel/Git integration should deploy from `main` if it is still connected. Check the latest deployment logs if the build fails.
